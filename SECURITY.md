# Security

Please do not report a vulnerability in a public issue.

- **In this package** (the scripts, nginx or systemd config, how secrets and backups are handled) -
  report it privately through [Report a vulnerability](https://github.com/ulsklyc/yuvomi_ynh/security/advisories/new)
  in this repository.
- **In Yuvomi itself** - follow [Yuvomi's security policy](https://github.com/ulsklyc/yuvomi/security/policy).

When unsure which one it is, use this repository; it is passed on if it belongs upstream.
