Yuvomi is a self-hosted family planner for one household. It brings the shared calendar, tasks, shopping lists, meal plans, budget, notes, contacts, documents and more into one installable web app (PWA), so a family does not need a separate subscription app for each.

### Features

- Shared calendar with Google and CalDAV sync, subscriptions and per-event visibility
- Tasks, shopping lists, meal plans and recipes for the whole household
- Budget, notes, contacts (CardDAV), documents, pantry, birthdays and more in the same place
- Installable on phones and desktops as a web app, no app store needed
- Database encrypted at rest (SQLCipher)
- REST API with scoped tokens, optional sign-in with OpenID Connect
- Available in several languages
