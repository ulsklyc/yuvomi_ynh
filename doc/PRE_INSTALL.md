Yuvomi needs its own domain or subdomain (for example `family.example.com`). It cannot be installed under a sub path such as `example.com/yuvomi`.

The installation creates the Yuvomi administrator from the YunoHost user you pick, with the password you enter here. Yuvomi keeps its own accounts: the other family members are invited from Yuvomi's admin page and do not need a YunoHost account.
