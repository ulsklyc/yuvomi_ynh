# Yuvomi for YunoHost

[Yuvomi](https://yuvomi.cloud/) is a self-hosted family planner. This repository packages it for [YunoHost](https://yunohost.org/).

**Status:** not yet in the YunoHost catalog. Install it from this repository:

```bash
sudo yunohost app install https://github.com/ulsklyc/yuvomi_ynh
```

- App source: <https://github.com/ulsklyc/yuvomi>
- Package documentation: [`doc/`](doc/)
- Report problems with the package here, problems with Yuvomi itself in the [app repository](https://github.com/ulsklyc/yuvomi/issues).
